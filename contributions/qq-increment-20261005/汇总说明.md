# QQ 爬取信息 · 源文件汇总说明

> 来源：`微信QQ信息助手_提交增量包.zip`（27 个文件，已脱敏：真实路径/账号/key/群名都换成了占位符）
> 整理日期：2026-10-05 · 在线下载地址：https://wechat-progress-board-1005-27000.netlify.app

## 一、QQ 爬取核心（就是这套让系统支持 QQ）

| 文件 | 干什么用 |
|---|---|
| `wechat-export/qq_export.py` | **主脚本**：QQ NT 群消息导出——剥掉数据库文件头 1024 字节 → sqlcipher3 解密 → 按白名单过滤 → 群名映射，输出格式和微信的导出完全一致，支持 `--date` 按天过滤 |
| `wechat-export/qq_auto_refresh.py` | **钥匙自动维护**：QQ 的解密密钥会变，这个脚本发现盐值变了就自动去 QQ 进程内存里抓新 key，顺便更新导出脚本；内置 sync_pinned（置顶表里新出现的群/个人自动进白名单）。可以挂成计划任务开机自动跑 |
| `wechat-export/qq_parse_msg.py` | QQ 消息是 protobuf 格式，这个负责把解密后的数据解析成可读消息 |
| `wechat-export/qq_pinned.py` | 提取 QQ 的置顶消息表（用来发现该关注哪些群） |
| `wechat-export/qq_decrypt_test.py` | 解密自测脚本，确认 key 和解密流程没问题 |
| `wechat-export/register_qq_task.ps1` | 一键注册 Windows 计划任务，让 QQ 自动刷新定时跑 |

## ⚠️ 使用前必读

1. **包里全是占位符**：路径、账号、key、群名都不是真的，直接跑不起来——要用得先按 `增量说明.md` 恢复成你自己的配置（QQ key 用 `qq_auto_refresh.py` 自动抓你自己的）。
2. **有 5 处要合并进主线**：`verify_entries.py`（QQ 双源+日期核对）、`feishu_notify.py`（签名）、`decrypt_db.py` / `daily_export.py`（WAL 修正）、三班次 prompt（QQ 节）——这些改动在贡献者手里，本包只有说明，要合并找维护者拿。
3. **新依赖**：QQ 解密需要 `sqlcipher3`（要本机编译工具链；装不上试 `sqlcipher3-binary`）。
4. **合规红线**：只读解密、不注入、不降级微信/QQ、密钥不外传。
