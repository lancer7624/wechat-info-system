# 增量包说明(提交给 wechat-info-system)

本包只含对方仓库没有的**新增文件**(已脱敏)。共有文件的改动见文末清单,由仓库维护者自行合并。

## 新增文件(按功能)

### 1. QQ 双平台整套(全新)
- `wechat-export/qq_export.py` — QQ NT 群消息导出:剥 1024 头 → sqlcipher3 解密 → 白名单过滤 → 群名映射,格式对齐微信 export,支持 `--date` 按天过滤
- `wechat-export/qq_auto_refresh.py` — QQ key 自动维护:读库盐、盐变自动扫 QQ 进程内存拿新 key(`x'<64hex><salt>'` 模式)、更新导出脚本、内置 sync_pinned(置顶表新增群/个人自动进白名单),可配计划任务开机跑
- `wechat-export/qq_parse_msg.py` / `qq_pinned.py` / `qq_decrypt_test.py` — protobuf 消息解析、置顶表提取、解密自测
- `wechat-export/register_qq_task.ps1` — 注册 QQ 自动刷新计划任务

### 2. 每周漏消息复盘(全新)
- `scripts/audit_weekly.py` — 周日 21:30 自动扫最近 7 天 @所有人 通知,和已推送记录比对,输出漏网候选报告

### 3. 置顶同步检测(全新)
- `scripts/detect_new_pinned.py` — 微信侧:白名单外今天有消息的会话清单(微信置顶名单加密读不到,用活跃度反推),报给用户确认后加白名单

### 4. 入库合并与双平台接线(全新)
- `scripts/merge_pending.py` — 核对通过的待审 json 合并进 kanban/data.json(去重)
- `scripts/add_dual_platform.py` — 一次性脚本:把双平台铁律插入 分类规则.md 和班次 prompt 的 QQ 节

### 5. 计划任务部署(全新)
- `scripts/deploy_tasks.ps1` / `scripts/add_logon_trigger.ps1` — 导出/班次计划任务注册与 AtLogOn 触发器

### 6. 导出补录与纯 RPM 内存扫描(全新)
- `wechat-export/backfill_export.py` — 把全量导出里目标日期消息补回对应日期目录(闸门按天核对用)
- `wechat-export/mem_scan_rpm.py` / `mem_scan_top.py` — 纯 ReadProcessMemory 内存扫描(不注入不 attach,frida 被反调试挡时的替代)
- `wechat-export/extract_anchors.py` — 锚点提取辅助

### 7. 多开二号微信 key 抓取系列(全新)
- `wx2_key_scan.py` / `wx2_key_scan3.py` / `wx2_key_scan4.py` — 二号多开实例 key 扫描(x'盐'模式/64hex 串/盐邻域熵窗口+频次)
- `wx2_dump.py` — MiniDumpWriteDump 全内存 dump(不注入不 attach,零风险)
- `wx12_verify.py` / `wx2_verify_hits.py` — dump 候选并行验证(页1魔数)
- `wx_key_probe.py` — 已知 key 对照实验探针(验证扫描方法有效性)
- `wx12_scan_dump.ps1` — C# 内联编译全内存熵窗口频次统计
- `wx2_config.json` — 二号白名单示例

### 8. 增强版规则(全新)
- `分类规则.md` — 实际生产规则,比模板多:双平台铁律(微信+QQ 都分析、platform 字段、飞书标题区分)、每周漏消息复盘铁律、直播/回放/班会也要推送、每条飞书推送带来源群聊全名、指示类要素铁律(人物/时间/地点必须写全)

## 共有文件的改动点(需维护者自行合并)

1. `scripts/verify_entries.py` — 加 QQ 双源:load_corpus 遍历微信+QQ 两导出目录;verify_quote 加日期核对(命中日期≠归档日期拦截);多引文时间戳聚合判定
2. `scripts/feishu_notify.py` — 飞书签名:HMAC-SHA256,config 加「飞书签名密钥」字段

4. `wechat-export/daily_export.py` — use_wal=False 生产默认;save_watermark / build_session_names / cleanup
5. `prompts/prompt_noon.md` / `prompt_evening.md` / `prompt_daily.md` — 加「0.5 QQ 源」节(QQ 白名单/独立水位/待审命名/双源闸门)
6. `prompts/prompt_trip.md` — 小改
